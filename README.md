
# AI Prompt Platform

## 📌 Project Overview

AI Prompt Platform is a Python-based web application project for Machine Learning-powered prompt classification.

The project integrates a trained ML model and text vectorizer with a web application for processing and classifying user prompts.

## 🚀 Project Features

- Machine Learning-based prompt classification
- Text processing and vectorization
- Python web application
- Web interface using templates and static files
- Login and signup testing scripts
- API testing components
- Local database integration

## 🛠️ Technologies Used

- Python
- Machine Learning
- Natural Language Processing (NLP)
- HTML, CSS, JavaScript
- Database Management
- Google Colab

## ⚙️ Installation

### 1. Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/AI_Prompt_Platform.git
```

### 2. Open Project Folder

```bash
cd AI_Prompt_Platform
```

### 3. Install Dependencies

Install the Python packages required by the application.

If you create a requirements.txt file, use:

```bash
pip install -r requirements.txt
```

## ▶️ Run Application

```bash
python app.py
```

Check the terminal for the application URL and any additional setup requirements.
